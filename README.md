# Генератор сертификатов дилера в Telegram (24/7 Render)

Готовый Telegram-бот для автоматической генерации персонализированных сертификатов дилера в форматах JPG и PDF.

## Настройка шрифтов, цветов и размеров
Все параметры текста настраиваются в файле `generator.py`:
- `DARK_BLUE` — цвет основного текста (название, ИНН, дата).
- `MUTED_BLUE` — цвет номера сертификата на синей плашке.
- `font_num`, `font_company`, `font_inn`, `font_date` — размеры шрифтов и файлы шрифтов (`.ttf`).
